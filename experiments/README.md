# Experiment Utilities

Run these modules from the repository root with `python -m`.

- `analysis/`: diagnostics and visualization utilities.
- `ablations/`: ablation training and evaluation utilities.
- `baselines/`: baseline checkpoint evaluation utilities.
- `evaluation/`: zero-shot and cross-dataset evaluation.
- `few_shot/`: few-shot adaptation experiments.

Some older scripts contain experiment-specific paths or protocols. Check their
arguments and data assumptions before using their results in the manuscript.
